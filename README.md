# Quill-Scripter
The Quill Scripter repository is here!

### The project:
The Quill Scripters (and the whole Quill office) whole premise is to make an office that doesn't have an annoying A.I bot on the top of your screen, no pop-ups that block the screen. It only has essentials and some fun things. Every feature is able to be turned off if you like.

### Adressment of A.I
Though AI is very helpful (and also taking over the world) the **Quill Team** doesn't use A.I, and were proud of that. No ai has been involved in designing and coding. The project is meant to be made by and made for humans.
