# Quill-Scripter
The repository for the Quill Scripter project is here!

# The project:
The Quill Scripters (and the whole Quill office) whole premise is to make an office that doesn't have the this-or-thats. It just has some essentials and some fun features that you can just ignore or turn off. No annoying assistent, no Ai-bot on the top of your screen. Pure calmness is the peak.
